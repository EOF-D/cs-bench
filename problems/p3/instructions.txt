You are on contract for a salvaging company to help them make maps of the stations they explore, using Python 3. Create a file called SectorMap.py with a class of the same name. This object must read in data from a file with a series of lines--each one starting with the letter "c" for  corridor, followed by the number of the two sectors it connects, then its length in meters (all of which are integers). For example a 15-meter hallway between sectors 14 and 18 would look like "c 14 18 15". The SectorMap should include a function get_length(a, b) which returns the length of the corridor between sector a and b (or None), and a function set_length(a, b, length) which does the inverse.
The company needs these maps to calculate paths for lighting and other logistics lines, as well as being able to provide arbitrary navigation between sectors for their engineers. These should be functions on SectorMap. jarnik() and takes no arguments and returns a list of corridors (identified by the sectors they connect), dijkstra(a, b) takes in the two nodes to be navigated between and returns a list of sectors to travel to. Both of these algorithms must be entirely your own implimentation, including a custom PriorityQueue with a binary heap. The PriorityQueue should be in its own file, with its main methods called push(item, priority) and pop() (which returns only the item or None). Its constructor should take in a list as base data, with each entry a list of [item, priority]
Your code must comply with the PEP 8 standard.
