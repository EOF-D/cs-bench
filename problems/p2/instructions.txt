You are responsible for a library to keep track of wizards, both apprentices and masters. Each class gets its own file, titled of the form [ClassName].py. The Wizard class holds the name and age of a given wizard, along with an array of spell names (as strings). The spell list starts blank. The Master class is a subclass of the Wizard that also stores the name of the master's school (as a string). The Apprentice class is a different Wizard subclass, this one with a reference to their Master (or None). 
All properties of these classes need getters and setters, named in the form get_[property]() and set_[property](). The spell list has a get, but should have seperate add_spell and remove_spell methods. remove_spell should do nothing if the spell is not in the list. All setters must verify that incoming data is of the appropriate type (and that age is not a negative number). Finally, when printed, a Wizard should return its name, a Master "[name] of [school name]" and an Apprentice "[name], apprentice of [master's name]". 
Your code must comply with the PEP 8 standard.
